# Imperial Common Go

Shared utilities for Death Star Operations Platform Go services.

## Packages

- **crypto** — Cryptographic helpers and encryption utilities
- **query** — Database query builder for structured data access
- **http** — HTTP client wrappers and request helpers
- **config** — Configuration loading and environment management
- **audit** — Audit logging for compliance and operational tracking

## Installation

```bash
go get github.com/endor-matt/imperial-common-go
```

## Usage

Import the package you need:

```go
import "github.com/endor-matt/imperial-common-go/pkg/crypto"
import "github.com/endor-matt/imperial-common-go/pkg/query"
import "github.com/endor-matt/imperial-common-go/pkg/http"
import "github.com/endor-matt/imperial-common-go/pkg/config"
import "github.com/endor-matt/imperial-common-go/pkg/audit"
```

## Requirements

- Go 1.21+
